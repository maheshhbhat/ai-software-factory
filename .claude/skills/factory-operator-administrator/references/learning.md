# Controlled learning loop

The operator improves through reviewed evidence, not silent prompt growth.

Record each material incident as:

`Observation -> Evidence -> earliest preventable cause -> owner -> classification -> lesson -> smallest correction -> falsifying test -> next-run validation`

Classify the lesson as product-specific, factory-systemic, environment-specific,
operator mistake, unproven, or deferred. A single unusual event is not a
universal policy unless its mechanism is demonstrated and recurrence matters.

Prefer the earliest inexpensive control that could have caught the problem.
Reuse an existing check before adding a deterministic validation, tested skill
procedure, regression case, or model judgment. Do not add an agent, service,
retry, or framework when a smaller control solves the demonstrated problem.

Every behavior-changing improvement follows:

1. Confirm no controlled measurement is active.
2. Preserve the original evidence and result.
3. Propose the bounded correction and risks.
4. Obtain required authorization.
5. Implement outside the autonomous factory when self-modification is forbidden.
6. Add a check that fails without the correction.
7. Review the actual diff and checks.
8. Merge only when authorized.
9. Measure recurrence, earlier detection, attempts avoided, human interventions,
   and false blocks in the next run.
10. Revise or remove a rule that causes more harm than it prevents.

Never retroactively credit a later correction to an earlier qualification.
